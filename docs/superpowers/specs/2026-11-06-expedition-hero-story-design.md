# 遠征島：森林守護者的五關故事

使用者已同意：固定一位在後方指揮施法的主角，五關故事；種族、能力、魔法、天賦、裝備都要存在，但各系統選項少。這份規格將已同意的方向落實為第一版數值；數值與角色名稱是實作者的設計選擇。

## 體驗與範圍

既有 Animal Siege 入口預設進入故事。主角「榛葉／Hazel」，森林聯盟的狐狸指揮官，沿用現有角色與海狸、狐狸、松鼠部隊美術。英雄不占戰場格、不接受普通攻擊。岩山與月影以敵方陣營登場，沿用三種兵種的戰鬥角色與美術，以陣營徽章、名稱和真正的能力差異表達。

每關含一場主戰、一次可選補給決策、可返回營地招兵升級；關卡順序固定，技能、法術與裝備由玩家選擇。完成後先顯示章節成果及故事，按繼續才開下一關。第五關使用唯一共用 ToenowScreens 結算；現有標題、四格分數、五級難度、分享、重玩、返回標題維持共用 library。

## 五關

1. 森林集結 / Forest Rally：空地救援，森林守衛叛軍；學會帶兵與固有庇護特長。完成獲得法術及第一件裝備。
2. 失落神殿 / Lost Shrine：河畔神殿；開始用治療、護盾和魔法箭。完成取得更多法術。
3. 山口爭奪 / Mountain Pass：岩山守軍有防禦加成，狹窄通道；出發前選擇一個永久天賦。完成取得新的武器與護符。
4. 月影迷境 / Moonlit Maze：森林障礙、靈活的月影軍；六種法術已解鎖，最多攜帶三個。補給選擇強調攻擊或守備。
5. 王城決戰 / Citadel Dawn：主堡，月影敵方英雄會在後方施法；完整運用裝備、天賦、兵種與魔法。

## 英雄與戰鬥契約

- Hero level 1–5 隨章節勝利成長，與 SDK wave 難度分開。四能力：attack、defense、power、maxMana；每級自動成長。攻防為部隊乘數，法強影響法術數值。
- 固有庇護：每場戰鬥一隊前排獲得護盾。第三關選 guardian（部隊防禦）或 sage（法術省魔）；僅能選一次。
- 六法術：heal（回復存活士兵的受傷生命，不復活）、shield（減傷）、bolt（單體傷害）、haste（移動 +2）、slow（移動 -2，最低 1）、inspire（下一次攻擊加成）。每位英雄每回合最多一次；所有行動前驗證敵我、存活、魔力、攜帶、解鎖、回合與結果。狀態到施法方下一回合開始失效，inspire 攻擊後即消耗。
- 六件裝備，weapon/charm 各一槽；每件只有一個效果。逐章獎勵，戰前替換，不能重複刷獎勵。法術與裝備都在中央英雄面板選擇。
- 英雄行動與部隊行動分開；魔法不消耗部隊移動或攻擊。戰鬥中顯示英雄、魔力、三個法術；點法術後在中央彈窗選合法目標並確認。
- 戰敗、撤退或首頁重新開始回到同一關出發前的軍隊、資源、英雄與魔力，可重試，已完成章節不丟失。勝利保存存活部隊並發放補給和援軍；勝利回營後依新裝備上限補滿魔力。平常更換裝備不回復魔力，降低上限會截斷目前魔力，避免反覆換裝補魔。明確向玩家說明。
- 岩山減傷、月影移動加成必須影響實際戰鬥，不只文案。第五關敵方英雄遵守同樣魔力和每回合一次規則。

## 存檔與介面

故事以獨立 versioned storage key 保存地圖／關卡間的進度與裝備；戰鬥中刷新回到出發前。自動保存失敗時仍能玩並顯示提示。損壞／舊版資料安全忽略。Practice 不讀取或覆寫故事存檔，不寫最高分。標題提供繼續冒險（若有存檔）和重新冒險（需確認才替換舊進度）。正常開始無角色選擇。

保留 full-row 地圖／戰場、中央彈窗、動物身上的部隊資訊；無側欄。支援英文／繁中、320/390/1280 寬度、觸控／鍵盤、Escape、關閉後焦點回復、暫停、重新開始及 iframe 返回原島。新文案在獨立語言目錄載入 i18n 前登記。

既有 mode=battle 單場與 mode=classic 三堡模式保留，舊引擎無英雄時結果不變。故事共用現有 SDK、軍隊、營地、動畫與資產；不新增依賴、不部署。

## 驗收

合法操作能打完五關；章節門檻、一次性獎勵、三法術上限、雙裝備槽、升級天賦、法術合法性／期限、敵方施法、失敗重試、存檔恢復與 practice 隔離均有測試。npm test、共用畫面瀏覽器回歸和故事專屬桌機／手機中英文真實操作通關必須完成。模擬尺寸不代表實體 iPad/Safari 驗證。
